Connexion

Ta connexion personnelle, les repas du foyer.

Demande un accès à l’administrateur du foyer.

Premier accès ou mot de passe oublié ?

Depuis le terminal du serveur, l’administrateur peut créer un compte :

docker compose exec manger node accounts.js create-admin admin

Pour récupérer un compte existant : remplace create-admin par reset-password et utilise son identifiant.

Revenir aux repas

Mot de passe

12 caractères minimum. Ce changement déconnecte tous tes appareils.

Accès au foyer

Ces comptes partagent les recettes, le planning et les courses. Les personnes à table se gèrent toujours dans « Mon foyer ».

    Un administrateur gère les accès, les sauvegardes et la restauration.

    La déconnexion efface les copies hors connexion de ce navigateur : courses et recettes.

    Connexion sur d’autres appareils

    Ferme toutes tes sessions, y compris celle-ci, sans changer ton mot de passe. Les autres membres restent connectés. Les copies déjà enregistrées sur un appareil hors ligne ne peuvent pas être effacées à distance.

    Connexion HTTP : utilise uniquement ton réseau de confiance ou ton VPN. Les comptes ne chiffrent pas les échanges ; HTTPS reste à configurer.
